# Răzeș MVP Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task. Steps use checkboxes for tracking.

**Goal:** Deliver a complete, visually coherent four-season household game implementing the user's brief.
**Architecture:** Pure deterministic rules and typed content drive a Phaser scene and accessible DOM interface. Local snapshots are validated before use.
**Tech Stack:** TypeScript, Vite, Phaser, Vitest, Playwright.
**Spec:** docs/superpowers/specs/2026-10-21-razes-design.md

## Global Constraints

- Three workers, four seasonal turns, eight encounters per run, no mid-run death.
- No backend, external credentials, deployment, or second year.
- Effects commit once; money cannot be negative; promises consume labour once.
- Scene and controls render the same authoritative state.
- Use existing isolated checkout; no additional worktree.

## Review Focus

- Stale/double actions must not duplicate costs or rewards (task 1).
- Corrupt/unsupported saves must show a recoverable message (task 2).
- Autumn's reserved worker must not be reassigned (task 1).
- Unaffordable combined assignments must be rejected (task 1).
- Keyboard and reduced-motion users must complete all seasons (task 4).

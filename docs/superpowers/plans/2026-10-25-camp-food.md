# Camp Food Implementation Plan

**Goal:** Camp → Eat → choose grain/grams → prepare and eat porridge.

**Spec:** `docs/superpowers/specs/2026-10-25-camp-food-design.md`

**Architecture:** Keep recipe/accounting in Human; retain the existing bag
renderer and extract its slot control. Add a camp menu and a food window beside
the existing HUD windows. Game owns camp picking and command routing.

**Shared interfaces:** Human.eat(farm, crop, grams) reserves a selected meal;
Human.porridge(crop, grams) returns hours/calories; meal_crop/meal_grams expose it.
Food window emits prepare_requested(crop: String, grams: int). Rest and Game
Over behavior remain unchanged. No migrations or new dependency.

- [x] Model and tests: explicit ingredient/amount validation, exact reservation,
  proportional recipe, completion and pending/death protections.
- [x] Reuse inventory bag slots in an inventory-style food selection window.
- [x] Camp menu, picking and keyboard route; remove direct HUD eating.
- [x] Scene tests for the requested path, closing, quantity and input boundaries.
- [x] Documentation, all test suites, GPU captures and final review.

All eight suites pass. Independent review's live-quantity preview and viewport
resize findings have regression checks, observed red then green, and are
re-reviewed as resolved. GPU captures at normal/minimum sizes confirmed the
retained slot font fixes bag weight rendering. Work remains uncommitted.

# Godot port validation

Checked on 2026-10-24 with Godot **4.7.2.stable.official.ed1daf0bf**, macOS 27.2, Apple M4, OpenGL 4.1/Metal Compatibility rendering.

## Completed

`./godot/test.sh` exits **0** for all five suites:

| Suite | Assertions/checks | Evidence |
| --- | ---: | --- |
| Rules | 3,905 | All commands, ownership/adjacency/negative coordinates, complete footprint validation, reserved money/materials, malformed action rejection, 144-week survival routine, strict save/report validation |
| Models | 10,264 | Every type, levels 1–5, damaged/winter/construction variants, rotated physical bounds, real textured meshes and shared resources |
| World | 72 | Coordinate round trips, camera/ray picking, physics selection of house/Ion, stable entities/surfaces, ghost/committed transform agreement, farmland, parcel picking and paint deduplication |
| Saves | 14 | Complete round trips including owned land, invalid/oversized state rejection, preservation of original bytes and previous valid household, explicit recovery/fresh start |
| Application | 24 | Reachable commands, compact HUD, weekly assignments/results/calendar, persistence, rejected land purchases, canceled plan cleanup, recovery dialog cancel/reopen flow |

Rules include **52 fixtures generated by the current native Swift implementation**, comparing resulting gameplay states and forecast numbers/character outcomes. The native fixture generator was compiled and executed; native/browser product files were not changed by the port.

The complete suites were also executed with normal engine permissions and clean output. Restricted execution emits a macOS system-certificate lookup error; that environment message disappears outside the sandbox. Godot's editor export cache also needs normal per-user cache access. No game networking is used.

Actual GPU viewport captures were generated by `tests/render_village.gd` and inspected for the starter household, all eleven building types in summer, rear winter view, expanded ownership and blocked placement. The initial header overflow and overexposed terrain were corrected after inspecting the real images. Buildings have visible ground contact, consistent relative scale and real shadows. Winter shading and rear geometry were inspected. These are modest procedural game models, not hand-authored final artwork.

Fresh code review identified malformed scenery IDs accidentally invoking remove-all, missing native scenery/plan/debug commands, invisible canceled-plan reservations, and a recovery-dialog cancellation trap. Each was corrected with failing regression checks followed by a passing suite. No important review finding remains open.

All three **macOS / Windows / Linux export presets** successfully generated `.pck` development data packs with exit **0**. The final Mac data pack also started headlessly with the installed engine and exited **0**, with no script/resource errors. Test sources are excluded from the packs. These data packs still require a Godot executable; they are not standalone application binaries.

## Limits and remaining checks

- Matching **4.7.2 export templates are not installed**. Standalone `.app`/`.exe`/Linux binaries were not generated. Presets and exact export commands are included in the README.
- Windows/Linux execution, Intel/minimum-macOS hardware, low-end GPU performance and physical trackpad behaviour have not been tested.
- Keyboard-focusable controls and labelled alternatives to map targets exist, but a full VoiceOver/NVDA/Orca audit has not been performed.
- No distribution signing, notarization, publication or installation was performed.
- Camera position/zoom/view angle are transient. Gameplay, building facing, land and comfort settings persist locally.
- The parcel limit of 48 × 48 and price of 20 Galbeni are initial implementation values, not playtest-balanced economy claims.
- The native/browser suites were not rerun because their product code is unchanged; generated native fixtures provide focused parity evidence for this port.
